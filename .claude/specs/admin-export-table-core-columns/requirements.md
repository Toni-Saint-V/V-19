# Requirements

### US-1: Быстро сканировать пакеты к выгрузке

**As a** администратор
**I want** видеть только ключевые данные пакета в строке
**So that** быстро нахожу нужную подачу перед выгрузкой

#### Acceptance Criteria (EARS)

1. WHEN экран «Выгрузка» показывает пакет
   THE SYSTEM SHALL показать ID вместе с именем и фамилией в левой смысловой ячейке.
2. WHEN экран «Выгрузка» показывает пакет
   THE SYSTEM SHALL показать даты поездки, город и агента как три отдельные смысловые ячейки.
3. WHEN строка отображается на desktop или mobile
   THE SYSTEM SHALL выровнять иконки по единому icon-rail.
4. WHEN строка содержит blocker или семейную подачу
   THE SYSTEM SHALL не добавлять вторичные blocker/count детали в четыре основные ячейки.
5. WHEN пользователь выбирает пакет или открывает правую панель
   THE SYSTEM SHALL сохранить существующее поведение.

## Non-functional requirements

- Не добавлять зависимости.
- Не менять export/domain logic, permissions, filters или sorting.
- Не допускать горизонтального overflow на 390px.

## Out of scope

- Переработка правой панели контроля.
- Изменение состава экспортного пакета.
- Изменение фильтров и статусов.
