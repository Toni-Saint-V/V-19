# V20 admin clickable actions patch

Цель патча — убрать «немые» действия в админке и сделать критичные состояния визуально различимыми.

## Что изменено

- Кнопки `OK` и `Замечание` в сверке полей меняют локальное состояние поля и показывают явное сообщение администратору.
- Выбор туриста в drawer переводит контекст на выбранного заявителя; кнопки `Открыть анкету` и `Файлы` меняют вкладку и показывают подтверждение действия.
- Экспортные кнопки больше не выглядят выключенными без причины: при клике показывают конкретное следующее действие или blocker reason.
- `Скачать ZIP с Excel` умеет автоматически подготовить Excel перед сборкой ZIP, если Excel ещё не был сформирован.
- Same-city пакеты с разными датами поездки теперь дают warning, а не blocker. Разные города остаются blocker.
- Local-demo storage key обновлён, чтобы старый v19 localStorage не держал сломанную/неполную очередь после установки патча.

## Проверено

Playwright покрывает:

1. Возврат заявки с замечанием и повторное принятие администратором.
2. Same-city date warning и mixed-city blocker.
3. Excel/ZIP package: сортировка, папки семей, имена по паспорту, PDF-анкета, marked exported.
4. Кликабельность OK/Замечание и feedback-контракт для Excel/ZIP кнопок.
