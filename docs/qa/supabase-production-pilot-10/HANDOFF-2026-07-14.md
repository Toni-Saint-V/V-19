4. Проверить движение карточки и согласованность статусов на всех agent/admin экранах после каждого перехода.
5. Admin закрывает issue и принимает пакет.
6. Admin формирует и скачивает Excel.
7. Admin скачивает ZIP на свежем коде.
8. До terminal RPC проверить ZIP bytes:
