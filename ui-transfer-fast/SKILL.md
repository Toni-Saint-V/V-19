# UI Transfer Fast Skill

## Purpose
This skill helps you quickly and accurately replicate an existing UI into your project while preserving layout structure, spacing, typography, and component hierarchy.

It is designed for fast UI migration from:
- screenshots
- Figma or design references
- existing web pages
- mockups or prototypes

## When to use
Use this when you need to:
- Rebuild an existing UI inside a new project
- Convert visual design into frontend code
- Match layout and spacing closely
- Speed up UI reproduction without redesigning

## Steps

### 1. Break UI into structure
- Identify layout (header/sidebar/content/footer)
- Split into sections and components

### 2. Extract visual rules
- spacing (padding/margins)
- typography
- colors
- alignment

### 3. Map to project components
- reuse existing components if possible
- create minimal new ones if needed

### 4. Implement top-down
1. Layout shell
2. Sections
3. Components
4. Fine-tuning

### 5. Validate
- spacing consistency
- alignment
- responsiveness basics

## Notes
- Do not redesign unless required
- Focus on structure, not creativity
- Keep components minimal
